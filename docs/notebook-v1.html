GIRO 2026 — completing a correlation matrix¶

Team members: Tim Harrison, Paul Hewson and Xinbin Xu.

Interactive demo · Python package and source · D10 slides

Question. Five standardised risk variables have six supplied pairwise correlations and four gaps. Complete the matrix while preserving the supplied information, making the extra assumptions visible and checking the result.

This notebook calls the shared vine_completion package used by the demo. It contains the worked calculation, rather than a second implementation of the completion algorithm. The inputs are illustrative ordinary Pearson correlations. They do not specify marginal distributions or a copula family.

1. Load the shared package¶

Run from the repository root or its notebooks/ folder. In a Python environment, install the package and optional plotting support with python -m pip install -e ".[plot]". NumPy and NetworkX perform the calculations; Matplotlib is used only for the diagrams. No model API or external data is used.

2. Specify the information¶

np.nan marks an unknown entry. A supplied zero would remain a fixed observation. Missing entries must be symmetric; the diagonal is one.

These are the explorer's rounded GIRO inputs. D10 rounds the displayed figures further; the computation below retains every supplied decimal. The original full-precision covariance example is separate, at the end.

3. Inspect the vine and state the free partials¶

The package's deterministic greedy rule prioritises edges whose partial correlations can be calculated from supplied information, then absolute strength. This is one choice of vine structure. The package checks spanning trees and the regular-vine proximity condition.

A dot denotes partial correlation, for example $\rho_{25\cdot1}$. The four orange edges below are additional choices, not supplied observations.

def partial_label(pair, conditioning):
    suffix = r"\cdot" + ",".join(map(str, conditioning)) if conditioning else ""
    return r"$\rho_{" + "".join(map(str, pair)) + suffix + "}$"

lookup = {row["key"]: row["partial_from_observations"] for row in plan}

4. Reconstruct a missing correlation¶

For the first free edge,

$$\rho_{25}=\rho_{21}\rho_{51} +\rho_{25\cdot1}\sqrt{(1-\rho_{21}^{2})(1-\rho_{51}^{2})}.$$

The known contribution is $(-0.586)(-0.374)=0.219164$. Choosing $\rho_{25\cdot1}=0$ therefore gives $\rho_{25}=0.219164$. The following call uses the package's general reverse-partial calculation.

In [6]:
cross, variance_2, variance_5 = conditional_moments(R, 2, 5, (1,))
scale = np.sqrt(variance_2 * variance_5)
rho_25 = correlation_from_partial(R, 2, 5, (1,), 0.0)
print(f"rho_25 = {cross:.6f} + 0.000000 × {scale:.6f} = {rho_25:.6f}")
assert np.isclose(rho_25, .219164, atol=1e-12, rtol=0)

rho_25 = 0.219164 + 0.000000 × 0.751506 = 0.219164

5. Complete the matrix and check the result¶

All four free partials are supplied explicitly. missing="error" prevents the package from silently filling an unspecified assumption. It reconstructs in tree order and rejects incompatible choices while preserving the supplied entries.

Zero partials on an arbitrary vine do not generally guarantee validity or maximum determinant. For this example we check both validity and the numerical maximum-determinant certificate, then compare with the separate chordal policy.

The free-position entries of $R^{-1}$ are numerically zero. Together with positive definiteness and preserved observations, this is the stationarity certificate for maximum log determinant under the original observed-entry constraints. It is separate from the feasibility checks and does not certify a different optimisation problem with additional partial-correlation constraints.

With a multivariate Gaussian model and fixed variances, maximum determinant also maximises differential entropy. Gaussianity is an additional model assumption.

6. Separate a modelling choice from the completion objective¶

For three variables, two ordinary correlations of 0.5 leave one gap. Maximum determinant gives 0.25. Supplying the partial correlation $\rho_{13\cdot2}=0.4$ instead gives $\rho_{13}=0.55$. The extra partial-correlation assumption changes the question being answered.

In [9]:
three = np.array([[1, .5, np.nan], [.5, 1, .5], [np.nan, .5, 1]])
baseline = complete_matrix(three, method="max_entropy")
alternative = complete_matrix(three, method="vine", strategy="d-vine", order=[1, 2, 3],
    partials=[{"conditioned": [1, 3], "conditioning": [2], "value": .4}], missing="error")
print(f"Maximum determinant, with only the two observations: rho_13 = {baseline.correlation[0, 2]:.2f}")
print(f"Explicit partial rho_13·2 = 0.4:                     rho_13 = {alternative.correlation[0, 2]:.2f}")
assert np.isclose(baseline.correlation[0, 2], .25)
assert np.isclose(alternative.correlation[0, 2], .55)

Scope and resources¶

  • The default exact maximum-determinant policy supports chordal observation graphs with positive definite specified cliques. General nonchordal optimisation and singular positive semidefinite completions are not implemented.
  • Explicit-vine choices can be incompatible. A rejected choice does not prove that the original partially specified matrix has no feasible completion.
  • A correlation matrix does not identify margins, a copula family, tail dependence or a direction of capital change. This is not an empirical insurance calibration.
  • A partial correlation describes regression residuals. It is not generally a correlation conditional on fixed values of the other variables.

Use the demo to change inputs and assumptions, the D10 slides for the conference walkthrough, and the repository to reuse the code.

Theory: Kurowicka and Cooke (2006), Completion problem with partial correlation vines. The code was extracted from the existing research notebook into the shared package. Codex assisted with packaging, presentation and validation. Earlier notebooks and versions are preserved separately.
